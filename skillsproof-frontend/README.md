# SkillsProof Frontend — BACISS 2026

A responsive React + Vite + Tailwind CSS frontend prototype for **SkillsProof**, an AI-assisted skills assessment and blockchain-verifiable credential concept.

## Quick start

Requirements: Node.js LTS and npm.

```bash
npm install
npm run dev
```

Open the localhost URL Vite prints (usually `http://localhost:5173`).

To build for production:

```bash
npm run build
npm run preview
```

## Frontend screens

- Candidate overview dashboard
- Assessment catalog
- SQL challenge editor (3 challenges)
- Technical interview (2 static demonstration prompts)
- Assessment status and scoring-rubric overview
- Credentials screen
- Credential verification placeholder
- Assessor review demonstration

## IMPORTANT: Demo-only functionality

This is a **frontend prototype**, not a secure, working credential authority.

- SQL queries are **not executed or graded**. The “Run query” button explains the missing integration.
- AI questions are **static placeholders**, not generated by Groq or Gemini.
- Assessment data lives in temporary React state and resets when the page reloads.
- Assessor approval is a **local UI demonstration**; a real backend must enforce user identity, assessor permissions and issuance eligibility.
- No credential is minted, registered or verified on Avalanche Fuji.
- There are no backend API calls yet. Backend and keys must remain on the server.

## Future integration

Implement Python/FastAPI backend routes for challenge submission and isolated SQLite grading, AI interview, human assessor review, credential issuance and verification. Add authentication, persistence, error handling and access controls before real use. Never place secret Groq/Gemini keys or blockchain signing keys in the frontend or `VITE_` variables.

## Recommended GitHub setup

Create an **empty private GitHub repository** named `skillsproof-frontend` (no README, .gitignore or license). Then from this folder:

```bash
git init
git add .
git commit -m "Initial SkillsProof React frontend"
git branch -M main
git remote add origin https://github.com/YOUR_USERNAME/skillsproof-frontend.git
git push -u origin main
```

Replace `YOUR_USERNAME` with your GitHub username. Git will prompt you to authenticate if necessary.
